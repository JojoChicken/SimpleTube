## Что умеет

- **Видео со звуком, только видео или только аудио.** Всегда лучшее качество, которое отдаёт YouTube, вплоть до 4K. Целые ролики сохраняются без пересжатия.
- **Любой кусок ролика.** Выбери начало и конец ползунком или впиши время, и программа скачает только этот фрагмент с точной обрезкой.
- **Музыка в хорошем качестве.** Целые треки сохраняются в оригинале, фрагменты в Opus 192 кбит/с.
- **Ссылку можно не вставлять.** Скопируй её в браузере и переключись на программу, она подхватит ссылку сама. Или перетащи ссылку прямо в окно.
- **Видео 18+.** Если YouTube просит подтвердить возраст, программа использует твой вход в YouTube из **Firefox** (нужно один раз войти и подтвердить возраст там).
- **Тёмный интерфейс** с обложкой видео на весь экран и кольцом прогресса.

## Как запустить

1. Скачай `SimpleTube-…-win64.zip` со [страницы релизов](https://github.com/JojoChicken/SimpleTube/releases/latest).
2. Распакуй архив **целиком** и запусти `SimpleTube-win32-x64\SimpleTube.exe`. Сам exe без папки рядом работать не будет.
3. При первом запуске Windows может показать «Windows защитила ваш компьютер»: программа не подписана сертификатом. Нажми **Подробнее → Выполнить в любом случае**.

## Если видео перестали скачиваться

YouTube время от времени меняет защиту, и движок нужно обновить. Выполни в PowerShell из папки программы:

```powershell
.\resources\tools\yt-dlp.exe -U
```

Не скачиваются закрытые видео, видео только для спонсоров канала, плейлисты и идущие прямые эфиры.

## Приватность

Программа общается только с YouTube. Никакой статистики, аккаунтов и серверов автора. Вход из Firefox для видео 18+ читается на твоём компьютере и уходит только в YouTube.

Скачивай то, что тебе разрешено сохранять: для личного просмотра.

<details>
<summary><b>Для разработчиков</b></summary>

<br>

Код приложения лежит в [`desktop/`](desktop): Electron + [yt-dlp](https://github.com/yt-dlp/yt-dlp) + [FFmpeg](https://ffmpeg.org/).

| Файл | Что делает |
|---|---|
| `desktop/main.js` | окно, IPC, проверка запросов из интерфейса |
| `desktop/engine.js` | запуск yt-dlp / ffprobe, прогресс, вход через Firefox для 18+ |
| `desktop/ui/` | интерфейс: разметка, стили, логика |
| `desktop/scripts/` | шаг после сборки и генератор иконки |
| `desktop/test/` | юнит-тесты, UI-тест, реальные загрузки через собранный exe |

Утилиты в репозиторий не входят: положи в папку `tools/` рядом с `desktop/` файл `yt-dlp.exe` и FFmpeg (сборка [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) full shared: `ffmpeg.exe`, `ffprobe.exe` и `*.dll`). Отдельный `node.exe` не нужен: yt-dlp использует Node.js, встроенный в Electron.

```powershell
cd desktop
npm ci
npm start              # запустить из исходников
npm test               # юнит-тесты
node test/ui.js        # интерфейс + реальная загрузка фрагмента
npm run package        # переносная сборка в ../release-v2
```

Подробнее (форматы, качество, тесты) в [`desktop/README.txt`](desktop/README.txt).

</details>
