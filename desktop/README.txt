SIMPLETUBE 2

Запуск: SimpleTube.exe из папки SimpleTube-win32-x64.
Программа переносная: копируйте папку целиком, включая resources.
Устанавливать Python, Node.js, FFmpeg или шрифт не нужно.

Вставьте ссылку, нажмите Paste, перетащите ссылку в окно — или просто
скопируйте её: при переключении на окно ссылка из буфера подхватится сама.
Появятся обложка, название и поля From / To.

From / To — начало и конец, ЧЧ:ММ:СС или ММ:СС. Можно тянуть ползунки под полями
(стрелки — по 1 с, Shift — по 10 с). «Use full video» возвращает весь ролик.

Пилюли слева направо: видео со звуком / только видео / только аудио.
Download сохраняет файл, кольцо на обложке показывает процент. Cancel отменяет.
После успеха кнопка становится Open in folder.
Ошибки показываются одной строкой под кнопками.
Сверху: жёлтая точка — свернуть, красная — закрыть. Верхнюю область можно перетаскивать.

Качество и форматы
— Целое видео: лучшее доступное качество, без пересжатия.
— Видео со звуком: один MKV; аудио отдельно: исходное качество Opus/M4A.
— Фрагмент: загружается выбранный диапазон; для точных видеограниц
  он перекодируется в H.264 с CRF 18. Разрешение исходной дорожки сохраняется.
  Это может занять время, особенно для 4K. HDR при такой обрезке не гарантируется.
— Кольцо показывает общий ход скачивания. Последние проценты —
  объединение и проверка файла. При неизвестном размере оценка приблизительная.
— В названии файла есть режим и диапазон; существующие файлы не перезаписываются.
— Отмена может оставить частичный файл рядом с результатом.

Закрытые ролики, вход в аккаунт, плейлисты и текущие прямые эфиры не поддерживаются.
Сохраняйте материалы, которые вам разрешено скачивать.

Настройки папки: %APPDATA%\simpletube\settings.json.
Обновление yt-dlp: resources\tools\yt-dlp.exe -U.

Оформление: Montserrat, локально в комплекте (SIL Open Font License).
Стеклянная панель преломляет только обложку внутри окна, не рабочий стол.

Разработка (исходники в desktop)
npm ci
node node_modules/electron/install.js
npm start
npm test
node test/integration.js — реальная загрузка короткого тестового фрагмента
node test/ui.js — интерфейс, реальная загрузка фрагмента и скриншоты в artifacts
npm run package — переносная сборка Windows
